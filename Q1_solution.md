# Question 1 — Bayes and Logistic Classification

## Experimental setup

Four independent iid datasets were generated with training sizes 20, 200, and 2,000 and validation size 10,000. NumPy SeedSequence(2024) was used to spawn four separate pseudorandom streams. Each sample was generated by drawing a label with probabilities (0.6, 0.4), selecting one of its two mixture components with equal probability, and drawing a Gaussian vector from that component. The same validation data were used for all seven classifiers. The validation set contains 5,998 class-0 and 4,002 class-1 samples. Training sets are independently generated, not nested subsets. The same training set at each size is used for both logistic model families.

The component means are

\[
m_{01}=(-0.9,-1.1)^T,\quad m_{02}=(0.8,0.75)^T,\quad
m_{11}=(0.1,0.9)^T,\quad m_{12}=(0.9,-0.75)^T.
\]

All components have covariance \(C=\operatorname{diag}(0.75,1.25)\), with mixture weights 1/2. Thus

\[
p_l(x)=p(x\mid L=l)=\tfrac12 g(x;m_{l1},C)+\tfrac12 g(x;m_{l2},C),
\]

where the two-dimensional Gaussian density is

\[
g(x;m,C)=\frac{\exp[-\tfrac12(x-m)^TC^{-1}(x-m)]}{2\pi\sqrt{\det C}}.
\]

## Part 1 — Minimum-probability-of-error classification

Under zero-one loss, the conditional error of choosing class 1 is P(L=0|x), and that of choosing class 0 is P(L=1|x). Therefore the minimum-error decision selects the larger posterior probability:

\[
\hat L(x)=\arg\max_{l\in\{0,1\}}P(L=l\mid x).
\]

Using Bayes' rule, select class 1 exactly when

\[
0.4p_1(x)\ge 0.6p_0(x)
\quad\Longleftrightarrow\quad
\frac{p_1(x)}{p_0(x)}\ge1.5.
\]

Define the discriminant score

\[
s(x)=\log p_1(x)-\log p_0(x).
\]

The optimal threshold is \(\tau^*=\log(1.5)=0.4054651081\). Predict class 1 when \(s(x)\ge\tau^*\), and class 0 otherwise. Ties may be assigned arbitrarily. Mixture log densities are evaluated using log-sum-exp for numerical stability.

The ROC is obtained by sweeping the threshold through all validation scores and plotting TPR against FPR:

\[
\mathrm{TPR}=\frac{TP}{TP+FN},\qquad \mathrm{FPR}=\frac{FP}{FP+TN}.
\]

The theoretical Bayes threshold is used for the marked point; it is not tuned using validation labels. At this point, FPR = 0.203234 and TPR = 0.466267. The confusion matrix, with true classes as rows and predicted classes as columns, is

\[
\begin{bmatrix}4779&1219\\2136&1866\end{bmatrix}.
\]

Hence the requested estimate of the minimum achievable error probability is

\[
\widehat P_e^{\mathrm{Bayes}}=\frac{1219+2136}{10000}=\boxed{0.3355}.
\]

The true Bayes error is \(\int\min\{0.6p_0(x),0.4p_1(x)\}\,dx\); 0.3355 is its Monte Carlo estimate, not an exact integral. The approximate standard error of this estimate is 0.00472.

## Part 2(a) — Logistic-linear approximation

Let \(\phi_1(x)=[1,x_1,x_2]^T\), and define

\[
q_w(x)=\widehat P(L=1\mid x)=\sigma(w^T\phi_1(x)),\qquad
\sigma(z)=\frac{1}{1+e^{-z}}.
\]

The other posterior is \(\widehat P(L=0\mid x)=1-q_w(x)\). Given training labels \(y_n\in\{0,1\}\), the conditional likelihood is

\[
\mathcal L(w)=\prod_{n=1}^N q_w(x_n)^{y_n}[1-q_w(x_n)]^{1-y_n}.
\]

Maximum likelihood therefore minimizes the negative log-likelihood:

\[
\hat w=\arg\min_w J(w),\qquad
J(w)=-\sum_{n=1}^N\left[y_n\log q_w(x_n)+(1-y_n)\log(1-q_w(x_n))\right].
\]

Equivalently, writing \(z_n=w^T\phi_1(x_n)\),

\[
J(w)=\sum_{n=1}^N\left[\log(1+e^{z_n})-y_nz_n\right],\qquad
\nabla J(w)=\sum_{n=1}^N[\sigma(z_n)-y_n]\phi_1(x_n).
\]

The implementation minimizes J/N with BFGS, using the analytic gradient and zero initialization. Dividing by N does not change the minimizer. No regularization or class weighting is applied. The stable softplus calculation uses numpy.logaddexp(0,z). All six optimizations converged successfully; their maximum absolute mean-loss gradient components were below 1e-9.

Classification uses

\[
\hat L(x)=\begin{cases}1,&q_{\hat w}(x)\ge0.5,\\0,&q_{\hat w}(x)<0.5.\end{cases}
\]

This is equivalent to thresholding \(\hat w^T\phi_1(x)\) at zero. The unequal priors are already represented in the training distribution; they should not be applied a second time to the learned posterior. The decision boundary is a straight line.

## Part 2(b) — Logistic-quadratic approximation

Use the expanded feature vector

\[
\phi_2(x)=[1,x_1,x_2,x_1^2,x_1x_2,x_2^2]^T.
\]

The estimated posterior is

\[
q_w(x)=\sigma(w_0+w_1x_1+w_2x_2+w_3x_1^2+w_4x_1x_2+w_5x_2^2).
\]

The likelihood, objective, optimizer, and 0.5 posterior threshold are unchanged, replacing the three-dimensional linear feature vector with the six-dimensional quadratic one. The decision boundary is the quadratic curve \(w^T\phi_2(x)=0\). Separate models are trained using each training dataset.

## Part 3 — Discussion

The quadratic classifiers outperform the linear classifiers at all three training sizes in this experiment. The two classes have multimodal distributions, and their true posterior log odds are differences of log-sums of Gaussian densities. Consequently, a linear score cannot adequately represent the Bayes decision boundary. Quadratic features allow curved boundaries and provide a substantially better approximation.

Increasing the number of training samples does not guarantee a monotonic decrease in validation classification error. In this run, linear error increases from 38.29% to 41.25% to 42.68%. These are independent random training sets, and maximum likelihood minimizes log loss rather than zero-one error. A misspecified linear model may approach its best population log-loss fit without approaching the Bayes rule. The comparatively favorable 20-sample result should not be interpreted as evidence that less training data are generally better. Even the always-class-0 rule has validation error 40.02%, illustrating that a fitted, misspecified logistic model is not guaranteed to improve zero-one loss over that baseline.

Quadratic error is 34.50%, 34.64%, and 33.89% for N=20, 200, and 2000. The small increase between 20 and 200 is compatible with sampling variability. The 2,000-sample quadratic classifier gives the lowest error among the trained models and is only 0.34 percentage points above the Bayes estimate in this run. A single run does not establish that this small difference is statistically significant. More data generally stabilize parameter estimation, but cannot eliminate model approximation error.

Although every Gaussian component has the same covariance, each class is a mixture rather than a single Gaussian. Thus neither a linear nor a quadratic logistic score is guaranteed to reproduce the true posterior exactly. The true-pdf Bayes classifier minimizes population error and supplies the theoretical benchmark. Finite validation estimates can fluctuate, so an empirical model could occasionally have a slightly smaller observed error without contradicting Bayes optimality.

## Reproduction

Install dependencies and run from the extracted folder:

```bash
python -m pip install numpy scipy matplotlib
python question1_solution.py
```

The program regenerates all four datasets, all four figures, and results/results.json. The JSON file includes full-precision fitted weights, confusion counts, optimizer status, and gradients. Feature orders are [1,x1,x2] for linear models and [1,x1,x2,x1^2,x1*x2,x2^2] for quadratic models. The compressed datasets are saved in results/datasets.npz. Minor numerical differences may arise across library versions, but the seed and data-generation procedure are fixed.
